### What is driving these inequalities? 

#### Simulation study
- Simulate surveillance data using a model which incorporates all of these driving factors
- Fit a model to this simulated data
- Evaluate recovery of unknown parameters (e.g. healthcare attendance rates)

#### Electronic health record analysis
- Run the same analysis on electronic health record (EHR) data 
- Use counterfactual analyses to determine drivers of observed inequalities
