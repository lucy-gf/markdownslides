## Compressing the dataset

### Principal Component Analysis (PCA)

A machine learning method to reduce the dimensionality of a dataset by measuring the key components driving difference between observations.

---

We can take a complex dataset which is defined by multiple variables (here 3, on the left), and perform PCA to produce vectors which capture the variance between observations. 

<img src="{{asset_folder}}/pca_example.png">

PC1 captures *the most* variance, then PC2, etc.

So in this case, the first principal component might look something like: <!-- .element: class="fragment" data-fragment-index="1" -->

<div class="fragment" data-fragment-index="1">
  \[ 0.4 \text{pub\_density} + 0.3 \text{proportion_in_professional_occupation} + 0.2 \text{cafe_price} + 0.1 \text{house\_prices} \]
</div>
